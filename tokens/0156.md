# BRC-156: Latched 1Sat Provenance for Basket `1sat` (Withdrawn)

Brandon Cryderman / HandCash (brandongcryderman@gmail.com)

**Status:** Withdrawn by the author. Do not implement.

> **Do not implement or cite this BRC.** It is withdrawn and has no normative content. Use [BRC-150](./0150.md) for 1Sat tip→origin provenance.

## Withdrawal notice

This standard has been withdrawn and its normative content removed. It defined an optional *latched* transfer profile (v3 provenance, O(1) verification) for 1Sat Ordinals tips held in basket `1sat`.

The author withdrew it because HandCash is not shipping the hardened Commit/Settle path that made the profile distinct; soft-latch tip naming alone did not justify a separate standard.

**Interoperable tip→origin provenance is [BRC-150](./0150.md)** — 1Sat Provenance Remittance for Basket `1sat`. Implementations that referenced this document should read BRC-150 instead. Basket custody remains [BRC-147](./0147.md).

## For implementers

- Wallets MUST NOT create latch outputs, latch markers or v3 provenance objects described by earlier revisions of this document.
- Wallets MUST NOT treat any of them as proof of origin. BRC-150 defines only v2, and treats any other version as non-conforming.
- Specifications MUST NOT cite this document as a way to follow an object's lineage. Cite BRC-150.

BRC number 156 is retired and will not be reassigned. This file remains only so that existing references resolve.
